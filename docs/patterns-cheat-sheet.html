How to tell them apart

Sliding Window vs Two PointersWindow: a contiguous range whose contents must satisfy a constraint; left moves only to restore it. Two Pointers: a pair condition on two positions, often on sorted input, pointers moving toward each other.
DP vs BacktrackingNeed one answer (count, max, yes/no) and the same sub-question repeats: DP. Need to list every solution: Backtracking. Backtracking + memo of a sub-question = top-down DP.
DP vs GreedyFind a counter-example where the locally best choice loses (2,7,9: taking 7 first gives 10, not 12). If one exists, it's DP.
Heaps vs Top K vs K-way MergeTop K: unsorted input, keep a size-K heap. K-way: inputs already sorted, heap of heads. Heaps: priority changes over time (scheduling, median, stream).
Tree DFS vs Tree BFSAnswer from subtrees or along a path: DFS. Per level, or nearest to the root: BFS.
Graphs vs Union FindStatic graph, need distances or traversal order: BFS/DFS. Edges arrive over time, only need "same group?": Union Find.
Graphs vs Topological SortDirected edges meaning "before", and you need an order or a cycle check: Topological Sort.
Hash Maps vs Knowing What to TrackMap as a lookup (complement, index): Hash Maps. Count first, then decide from the counts: Knowing What to Track.

Input size hints the complexity

  • n ≤ 20: O(2n) or O(n!): Subsets, Backtracking
  • n ≤ 500: O(n3): interval DP
  • n ≤ 5,000: O(n2): 2D DP, nested loops
  • n ≤ 105-106: O(n log n) or O(n): sort, heap, window, two pointers, BFS
  • Values up to 109, sorted or monotonic: binary search the answer

Interview checklist

  • Restate the problem; confirm input range, empties, duplicates, negatives
  • Name the signal phrase and the pattern out loud
  • Give brute force and its complexity, then the better approach
  • Code; then trace the example by hand
  • Edge cases: length 0/1, all equal, all negative, overflow
  • State time and space; mention one follow-up
