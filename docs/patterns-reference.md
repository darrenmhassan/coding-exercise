# Programming Patterns Reference

This comprehensive reference guide covers essential programming patterns for problem-solving and algorithm design.

## Pattern Overview

| Pattern | Description | When to Use | Example Questions |
|---------|-------------|-------------|-------------------|
| **Two Pointers** | Two pointers process data simultaneously | Linear data structure: the input data structure can be traversed in a linear fashion (array, LL, string). Process pairs: process data elements at two different positions simultaneously. Dynamic pointer movement: pointers move independently. | Given an array of integers, move all zeros to the end of the array. Find any three values in a sorted array that sum up to 825. |
| **Fast and Slow Pointers** | One pointer moves at a different speed to the other (2x, 3x, ...) | Linear data structure: the input data structure can be traversed in a linear fashion (array, LL, string). Cycle or intersection detection: the problem involves detecting a loop within a LL or array or finding an intersection between two LLs or arrays. Find the starting element of the second quantile. | Detect a cycle in a LL. Identify if repeatedly computing the sum of squares of the digits of number 19 results in 1. |
| **Sliding / Dynamic Window** | Add and subtract from a data structure as the window moves | Contiguous data: the input data is stored in a contiguous manner, such as an array or string. Process subsets of elements: the problem requires repeated computation on a contiguous subset of data elements (a subarray or substring). Efficient computation time complexity. | Given a string S and a string T, find the shortest substring in S that contains all of the characters in T. Given an array of integers and a target sum, find the length of the smallest subarray whose sum is greater than or equal to the target sum. |
| **Merge Intervals** | 1. Sort intervals by start time. 2. Compare first interval to next. | Array of intervals: the input is structured as a collection of intervals, such as meeting times. Overlaps, gaps, or conflicts: the problem requires reasoning about how these intervals relate, whether they overlap, leave gaps, or collide. | Schedule three interviews for an interviewer in one day. For a football tournament, find the duration during which more than one game are played simultaneously. |
| **In-place LL Manipulation** | 1. Three pointers: prev, curr and next. 2. Update curr to point to prev. 3. Move pointers one place. | Linked list restructuring: the input data is given as a LL and the task is to modify its structure without modifying the data of the individual nodes. In-place modification: space complexity shouldn't grow with input size, i.e. O(1). | Given a LL, bring all nodes with negative values at the start of the LL. Sort a LL. Given a LL of length 10, reverse nodes from position 3 to 7. |
| **Heaps** | Min, Max Heap or Priority Queue. Add and delete: O(log n), Peek or poll: O(1) | Linear data that can be sorted or unsorted. Stream of data: data arrives in an unpredictable order and requires efficient handling. Calculation of max or min. Custom priority-based selection. | Sort the characters of the given string by frequency (single heap). Given an array of unique scores, rank them based on their scores (single heap). Design a data structure to store a collection of integers supporting the (1) add to collection, (2) find median element operation. |
| **K-way Merge** | Repeatedly adding the smallest element among K sorted lists to an output list. Insert the first element of each list into a min heap. Keep track of which list the element came from. Or merge pairs of lists. | Involves merging sorted arrays or a matrix: a collection of sorted arrays or a matrix with rows or columns sorted in a specific order that needs to be merged. Seeking the Kth smallest/largest across sorted collections. | Merge 5 sorted arrays. Find the 2nd smallest number in 20 sorted arrays. |
| **Top K Elements** | A heap of K size | Unsorted list analysis: we need to extract a specific subset of elements based on their size (largest or smallest), frequency (most or least frequent), or other criteria from an unsorted list. Identifying a specific subset: the goal is to identify a subset rather than just a single extreme value. | Rearrange the given string so that no two identical characters are adjacent to each other. Find the five nearest points to the origin. |
| **Modified Binary Search** | 1. Compare the target with the middle. 2. If less than middle move end to middle -1. 3. If greater than middle move start to middle+1. | Target value in sorted data: identifying a specific target value, or identifying its first or last occurrence, within a sorted array or list. Partially sorted segments: when segments of an input array are sorted. | Check if a number is the majority element in a sorted array. Find a peak element in an array where the peak element is the one that's strictly greater than its immediate left and right neighbors. |
| **Subsets** | 1. Start with the empty set. 2. For each element copy the subsets and add the element to them. | Requirement for combinations or subsets: generate combinations (or subsets) of the elements from the input data structure. | Find any one subset in a set of elements whose sum adds up to 12. Generate the power set of the set {1, 2, 3}. |
| **Greedy Algorithm** | Locally optimal choices lead to a globally optimal outcome | Optimization problems: we are looking to find the best solution under a given set of constraints, such as minimizing or maximizing some value (e.g. cost, distance, time or profit). | Find the shortest period of time to schedule a set of jobs on a set of machines. Find the shortest path between two intersections on a road map. Find the most cost-effective way to lay an optical fiber cable in a neighborhood. |
| **Backtracking** | Recursive. 1. Base case. 2. If all paths (states) have been explored backtrack to previous point (state). 3. If the current point (state) is not a dead-end, keep progressing towards the solution. | Complete exploration is needed for any feasible solution: the problem requires considering every possible choice to find any feasible solution. Selecting the best feasible solution: the goal is to find the best solution amongst all feasible solutions. | Find all the ways to place 5 queens on a 5 x 5 chessboard. Maximize the revenue we can make by cutting-up a rod into pieces of different lengths, where each length may fetch different prices. |
| **Dynamic Programming** | The solution to a smaller problem helps us solve a larger problem. We need to solve the same subproblem repeatedly. Top-down: save the result of function calls. Bottom-up: iteratively fill a table with results of subproblems. | Overlapping subproblems: we can use the results of one subproblem when solving another, possibly larger subproblem. Optimal substructure: the final solution can be constructed from the optimal solutions to its subproblems. | Given a set, return the number of subsets whose sum equals 10. Maximize your heist without robbing neighboring houses. |
| **Cyclic Sort** | Start at the first element and iteratively swap it with the element at the position where it should be located | Limited range integer array: an input array of integers in a small range. Find missing or duplicate elements in an array. | Given a string representing a number, return the closest number that is a palindrome. Given a set of numbers, find the first 5 missing positive numbers. |
| **Topological Sort** | 1. Create a graph of node to directed neighbor. 2. Add nodes with no in-edges to a queue. 3. Remove nodes from the queue and add them to the topologically sorted list. 4. Add neighbors to the queue. 5. Finish when queue is empty. | Dependency relationships: the problem involves elements (e.g. tasks, jobs, elements) with dependencies that create a partial order and topological sort can be used to create a total order. Ordering or sequencing: the problem requires determining a valid order or sequence to perform tasks, jobs, activities, considering their dependencies or prerequisites. | Given a sample of words in an alien language, deduce the order of the letters in their alphabet. Determine if a sequence can be uniquely reconstructed from a set of subsequences. |
| **Sort and Search** | 1. Sort the data. 2. Apply a search technique, like binary or two pointer. The sliding window can be used to search subsets of data. Greedy algorithms can be used to make optimal decisions at each step. | Sortable data: the input data can be sorted. Pairwise and ordered comparison: comparing pairs or subsets of data to identify specific relationships or conditions, where these comparisons depend on the relative order of the elements. Range-based values: the task involves identifying or processing elements within a specific range or threshold. Optimization based on relationship: optimizing a solution by evaluating how data elements relate, such as finding max or min values or optimal distances between them. Efficient searching methods: benefits from efficient searching methods like binary search, two-pointer traversal, sliding window. | Given a collection of envelopes, each with a width and height, find the maximum number of envelopes you can Russian doll. Given an array of integers and another array of queries, return an array where each element represents the largest subsequence size from the first array such that the sum of subsequences is less than or equal to the corresponding value in the second array. |
| **Matrices** | Working with 2D arrays | 2D array input: the input data consists of a 2D array. | Given an m x n integer array where each cell represents a pixel value, update each pixel to the avg of itself and its surrounding pixels. Given an m x n map of server center, where each cell is either 1 or 0, return the number of servers that can communicate with at least one other in the same row or column. |
| **Stacks** | Operations: 1. Push O(1), 2. Pop O(1), 3. Peek O(1), 4. isEmpty O(1), size O(1) | Reverse order processing: processing elements in reverse order or requires the last element added to be first. Nested structures handling: like parentheses, brackets, or nested function calls. State tracking: requires keeping track of previous states or undoing operations. Expression evaluation: evaluating expressions. | Check if the parentheses in a math expression are balanced or not. Convert an infix expression (like 3 + 4 x 5) to postfix notation (like 3 4 5 x +). |
| **Graphs** | Graph traversal: 1. DFS - implemented with: a stack of to-be-traversed nodes, a list of visited nodes. 2. BFS - implemented with: a queue of to-be-traversed nodes, a list of visited nodes. | Relationships between elements: there is a network of interconnected objects with some relationship between them. | Given multiple paths from city A to city B, find the shortest path to reach city B from city A. Given a network of routers connected to each other, find such a path between two routers whose removal will fail the communication across the network. Given an n x n binary matrix grid, find the length of the shortest clear path in the matrix. |
| **Tree DFS** | Recursive solution: Pre-order: root, left, right. In-order: left, root, right. Post-order: left, right, root. | Tree data structure: undirected, acyclic (DAG). Balanced/low branching factor. Hierarchical structures. Solution near the leaves. Traversal along paths: components of the solution are listed along paths from the root to the leaves. Explore all possible paths: the problems requires exploring all possible paths in the tree. | Find the zig-zag level order traversal of a binary tree. Find the lowest common parent node of two given nodes in a binary tree. |
| **Tree BFS** | Explores the tree level-by-level. Iterative solution: 1. Initialization: start from the root node by placing it in a queue. 2. Remove the node from a queue and add its child nodes to a 2nd queue. Alternate between queues. Terminate when the desired node is found or all nodes have been explored. | Tree data structure: undirected, acyclic (DAG). Not a wide tree. Level-by-level traversal. Solution near the root. | Traverse a tree one level at a time and print out the node values in the same order. Find the shortest path between two given nodes, u and v, in a binary tree. Connect all of the nodes at the same level in a binary tree. |
| **Trie** | A tree that stores keys where each node is a letter in the key. Operations: insert(word) O(m), search(word) O(m), delete(word) O(m) where m is the length of the word. | Partial matches: compare two strings to detect matches based on the initial characters of one or both strings. Space optimization: optimize the space used to store a dictionary of words. Can break down the string into individual characters. | Implement a contact list where you can search for contacts by name efficiently. Find all the words in a dictionary that start with "aba". |
| **Hash Maps** | Hash the Key to a value, such as an index in an array. Operations: insert(key, value) O(1), search(key) O(1), remove(key) O(1). Deal with collision using chaining or open addressing. | Data access: we require repeated, fast access to data during the execution of an algorithm. Pair-wise relation. | Find four elements a, b, c, and d in an array such that a + b = c + d. Divide an array into pairs whose sum is divisible by 2. |
| **Knowing What to Track** | 1. Counting phase 2. Utilization phase | Frequency tracking. Pattern recognition: patterns in data where certain elements or combination of elements repeat. Fixed set of possibilities. | Given a string, count the substrings that have all of the vowels. Given a string, check if any of its permutations can form a valid palindrome. |
| **Union Find** | find(v): find the representative of the set that contains v. union(v1, v2): merges the sets containing v1 and v2 into one. | Property-based grouping: arrange elements with a certain property into groups. Set combination: a problem that contains elements represented as separate sets initially where we have to combine pairs of sets or find whether two elements belong to the same set or not. Graph data organization: the data is best organized in the form of a graph, yet the data has not been provided in the form of an adjacency list/matrix. | In a row of seats, couples are sitting together. Find the minimum number of swaps required to make every couple sit side-by-side. Given an undirected graph represented as an array of edges, determine whether the graph contains a cycle. |
| **Custom Data Structures** | Build new data structures from: arrays, LLs, maps, trees. | Modification of an existing data structure, such as min stack or maximum frequency stack. Multiple data structures involved: combining one or more data structures to solve the problem, such as Least Recently Used (LRU) cache. | Implement arbitrary state persistence of multiple worker nodes to improve the fault tolerance of a distributed system. Enhance a stack to enable popping the highest value in O(1). |
| **Bitwise Manipulation** | Working with individual bits | Bit-level operations and optimizations | |
| **Math and Geometry** | Mathematical and geometric problem solving | Mathematical computations and geometric relationships | |

## Quick Reference by Category

### Array/String Processing
- **Two Pointers**: Linear traversal with two pointers
- **Sliding Window**: Contiguous subarray/substring problems
- **Cyclic Sort**: Limited range integer arrays

### Tree/Graph Algorithms
- **Tree DFS**: Depth-first traversal, path-based solutions
- **Tree BFS**: Level-by-level traversal, shortest path in trees
- **Graphs**: Network relationships, connectivity problems
- **Topological Sort**: Dependency ordering

### Optimization Patterns
- **Greedy Algorithm**: Local optimal choices
- **Dynamic Programming**: Overlapping subproblems
- **Backtracking**: Complete exploration with pruning

### Data Structure Patterns
- **Heaps**: Priority-based processing
- **Stacks**: LIFO processing, expression evaluation
- **Hash Maps**: Fast lookups and frequency tracking
- **Trie**: Prefix-based string operations

### Advanced Patterns
- **Union Find**: Disjoint set operations
- **Custom Data Structures**: Specialized requirements
- **Bitwise Manipulation**: Bit-level optimizations
